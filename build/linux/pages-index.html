Object Storage Client for Linux

Install the stable release from the signed APT or DNF repository.

APT (Debian and Ubuntu)

sudo install -d -m 0755 /etc/apt/keyrings
wget -O repository-key.asc https://devcode-kr.github.io/object-storage-client/repository-key.asc
gpg --dearmor --output object-storage-client.gpg repository-key.asc
sudo install -m 0644 object-storage-client.gpg /etc/apt/keyrings/object-storage-client.gpg
printf '%s\n' 'deb [arch=amd64 signed-by=/etc/apt/keyrings/object-storage-client.gpg] https://devcode-kr.github.io/object-storage-client/apt stable main' | sudo tee /etc/apt/sources.list.d/object-storage-client.list > /dev/null
rm repository-key.asc object-storage-client.gpg
sudo apt update
sudo apt install object-storage-client

DNF (Fedora and compatible distributions)

Save this as /etc/yum.repos.d/object-storage-client.repo:

[object-storage-client]
name=Object Storage Client
baseurl=https://devcode-kr.github.io/object-storage-client/rpm/stable/x86_64
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://devcode-kr.github.io/object-storage-client/repository-key.asc
sudo dnf install object-storage-client
